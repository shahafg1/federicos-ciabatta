# Federico’s Ciabatta 🥖

משחק דוכן צ׳אבטה בעברית: מכינים הזמנות, ממלאים מלאי ומפנקים לקוחות בקמבוצ׳ה.

## לשחק

https://federicos-ciabatta.netlify.app

## הפעלה מקומית

```sh
python3 -m http.server 4188 --directory dist
```

פתחו http://localhost:4188 בדפדפן. אין צורך בהתקנת תלויות או בתהליך בנייה.

## בדיקות

```sh
node --test tests/engine.test.mjs
```

## מבנה

- `dist/` — קוד המקור של המשחק, איורים ושיר הרקע.
- `tests/` — בדיקות מנוע המשחק.
- `netlify.toml` — הגדרות פרסום סטטי.

המשחק תומך במחשב ובנייד. כפתור שמע אחד מפעיל ומשתיק את המוזיקה והאפקטים.

## תרומות וזכויות

אפשר לפתוח Issues ולהציע שיפורים באמצעות Pull Requests. המאגר ציבורי; לא הוענק בשלב זה רישיון שימוש כללי לקוד, לאיורים או למוזיקה. תמונות המקור וחומרי העבודה הפרטיים אינם כלולים במאגר.
